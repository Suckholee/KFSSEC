# 홈페이지 관리자 운영 안내

## 회원 관리

홈페이지 관리자 도구의 회원관리를 누르면 별도 페이지 `/admin/members`가 열린다. 관리자 센터의 정회원·일반 회원 관리 메뉴에서도 접근할 수 있다.

- 일반 회원: 홈페이지에 가입한 회원. 신규 가입자는 일반 회원으로 등록된다.
- 정회원: 교육원에서 확인한 정회원. 관리자가 직접 구분을 변경한다.
- 전체 회원, 정회원, 일반 회원 카드를 눌러 목록을 필터링한다.
- 이름, 연락처, 이메일, 업종, 소속, 직위 또는 아이디로 검색할 수 있다.
- 회원 행의 구분 변경을 누르고 회원 구분을 선택한 뒤 저장한다. 저장 성공 안내 후 목록과 집계가 갱신된다.
- 회원 구분 변경은 관리자 권한 부여와 별개다. 회원 본인은 프로필 수정으로 회원 구분을 변경할 수 없다.

## 공지 배너와 게시글 연결

관리자 센터의 홈화면 관리에서 메인 히어로 배너 관리를 연다. 슬라이드를 선택하고 텍스트 설정의 버튼 이동 위치에서 공지 게시글을 선택한다. 홈페이지에 저장한 후 배너를 눌러 선택한 게시글이 열리는지 확인한다. 개인정보를 담은 문의 게시글은 연결 목록에서 제외된다.

## 상담 사전정보

창업 상담 사전정보에서 청년 창업 상담 또는 일반 창업 상담을 선택한다. 연령대, 준비 단계, 관심 업종, 경험, 예산, 희망 지역, 시기, 상담 분야와 방식을 입력한다. 임시저장은 현재 브라우저에만 저장된다. 신청 성공 후 임시 답변은 삭제된다.

## 교육원에서 확인하거나 제공할 자료

- 회원가입을 상담 신청의 필수 조건으로 할지 결정
- 회원 정보의 필수·선택 항목 확정
- 공식 행사 사진과 인물 프로필 사진
- 명인·명장 심사 기준과 신청서 원본
- 공식 자격과정 자료 및 안내 문구
- 정확한 명함 연락처와 주소
- FAQ 및 1대1 상담의 표준 답변

관리자 개인별 인증 계정, 전체 콘텐츠 작업 로그 및 회원 본인의 문의 내역 조회는 추가 구현 대상이다. 현재 공통 관리자 인증과 문의 게시판을 개인별 운영 기능으로 간주해서는 안 된다.
