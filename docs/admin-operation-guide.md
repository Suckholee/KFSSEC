# 홈페이지 관리자 운영 안내

## 회원 관리

홈페이지 관리자 도구의 회원관리를 누르면 별도 페이지 `/admin/members`가 열린다. 관리자 센터의 정회원·일반 회원 관리 메뉴에서도 접근할 수 있다.

- 일반 회원: 홈페이지에 가입한 회원. 신규 가입자는 일반 회원으로 등록된다.
- 정회원: 교육원에서 확인한 정회원. 관리자가 직접 구분을 변경한다.
- 전체 회원, 정회원, 일반 회원 카드를 눌러 목록을 필터링한다.
- 이름, 연락처, 이메일, 업종, 소속, 직위 또는 아이디로 검색할 수 있다.
- 회원 행의 구분 변경을 누르고 회원 구분을 선택한 뒤 저장한다. 저장 성공 안내 후 목록과 집계가 갱신된다.
- 회원 구분 변경은 관리자 권한 부여와 별개다. 회원 본인은 프로필 수정으로 회원 구분을 변경할 수 없다.

## 공지 배너와 게시글 연결

관리자 센터의 홈화면 관리에서 메인 히어로 배너 관리를 연다. 슬라이드를 선택하고 텍스트 설정의 버튼 이동 위치에서 공지 게시글을 선택한다. 홈페이지에 저장한 후 배너를 눌러 선택한 게시글이 열리는지 확인한다. 개인정보를 담은 문의 게시글은 연결 목록에서 제외된다.

## 상담 사전정보

창업 상담 사전정보에서 청년 창업 상담 또는 일반 창업 상담을 선택한다. 연령대, 준비 단계, 관심 업종, 경험, 예산, 희망 지역, 시기, 상담 분야와 방식을 입력한다. 임시저장은 현재 브라우저에만 저장된다. 신청 성공 후 임시 답변은 삭제된다.

## 교육원에서 확인하거나 제공할 자료

- 회원가입을 상담 신청의 필수 조건으로 할지 결정
- 회원 정보의 필수·선택 항목 확정
- 공식 행사 사진과 인물 프로필 사진
- 명인·명장 심사 기준과 신청서 원본
- 공식 자격과정 자료 및 안내 문구
- 정확한 명함 연락처와 주소
- FAQ 및 1대1 상담의 표준 답변

관리자 개인별 인증 계정, 전체 콘텐츠 작업 로그 및 회원 본인의 문의 내역 조회는 추가 구현 대상이다. 현재 공통 관리자 인증과 문의 게시판을 개인별 운영 기능으로 간주해서는 안 된다.

## 페이지에서 직접 내용 편집

1. 관리자 로그인 후 수정할 페이지와 하위 메뉴를 연다.
2. 영역 상단의 **내용 편집**을 누른다. 상단 툴바의 **현재 페이지 내용 편집**에서는 메뉴·로고·하단 정보까지 함께 찾을 수 있다.
3. **제목 영역**, **설명·본문 영역**, **목록 항목 영역**, **이미지 주소 영역**, **버튼·링크 이동 주소 영역** 표시를 보고 수정한다. 현재 문구로 검색할 수 있다. 일반 문구는 두 번 클릭해 해당 항목만 열 수도 있다.
4. **수정 내용 적용**을 누르면 관리자 미리보기에 적용된다. 상단 **전체 저장**을 눌러야 홈페이지에 저장되고 방문자에게 반영된다.
5. **방문자 시점**에서 편집 안내 없이 결과를 확인한다. 저장 전에는 툴바에서 되돌릴 수 있다. 편집창의 닫기는 해당 창에서 아직 적용하지 않은 변경을 취소한다.

- 우클릭은 필수가 아니다. 영역 설정의 점 세 개 버튼에서는 표시·순서 설정과 기존 상세 관리 기능을 이용할 수 있다.
- 안내 막대는 본문과 별도 줄에 표시되어 제목과 영문 문구를 가리지 않는다. 편집 중에는 스크롤 등장 효과를 해제하여 내용을 바로 확인한다.
- 이미지 파일은 JPG·PNG·WebP, 최대 4MB이며 업로드 또는 이미지 주소 입력으로 교체한다. 동영상은 영상 주소를 수정한다. 이미지에 그려진 글자는 이미지 자체를 교체해야 한다.
- 다른 탭, 접힌 메뉴, 팝업 등의 내용은 해당 화면을 먼저 열고 편집한다. 일반 문구는 선택한 언어별로, 이미지·영상·이동 주소는 공통으로 적용된다. 기존 전용 편집기는 해당 원본 데이터에 저장한다.
- 공통 편집은 공개 콘텐츠의 표시를 수정한다. 회원 정보, 신청 내역, 결제·수강 상태 같은 업무 데이터는 기존 관리 메뉴에서 수정한다. 새로운 항목 추가·삭제 등 목록 구조 변경도 기존 상세 관리 기능을 이용한다.

### 개발 시 편집 누락 방지

`vite.config.js`의 `direct-content-plugin`이 공개 컴포넌트의 네이티브 JSX 문구·이미지·영상·링크에 공통 편집 연결을 추가한다. 기존 `EditableText`·`EditableImage`는 중복 처리하지 않고 같은 편집창에 원본 데이터 수정 기능을 등록한다. 관리자 도구·회원 인증·사용자 게시글 작성기·실시간 대화는 자동 처리에서 제외한다.

추가 표시 문구는 `site.contentOverrides`에 저장되며 기존 관리자 인증과 콘텐츠 저장 API를 사용한다. 연결은 컴포넌트·원문·언어별로 구분한다. 코드에서 원문이나 해당 요소를 바꾸면 연결이 바뀔 수 있으므로, 이미 운영 중인 문구는 관리자 편집으로 변경한다. 대규모 마크업 개편 시 기존 표시 수정값의 이전 여부도 확인한다.

검증: `node --test scripts/direct-content.test.js`, `npm run build`. 2026-10-20 기준 공개 컴포넌트 57개를 정적 점검하고 주요 7개 메뉴에서 편집창 연결을 확인했다. 제목·설명·기존 이미지·여러 배너의 적용과 저장 요청, 새로고침 후 복원, 방문자 모드 및 390px 모바일 편집창은 로컬 테스트 저장소에서 확인했다. 운영 데이터베이스에 테스트 문구를 쓰지 않았다.

## 자격과정 FAQ 목록 관리

**교육·자격증 → 자격과정 안내** 또는 **자격 시험** 화면 하단의 자주 묻는 질문에서 **FAQ 목록 관리**를 누른다. 두 화면의 모든 자격과정이 같은 FAQ 목록을 사용한다. 커뮤니티의 주요문의 FAQ와는 별도다.

- 질문 제목과 답변 내용을 입력한다. 기존 질문을 펼치지 않고도 전체 답변을 확인할 수 있다.
- **질문 추가**, **삭제**, **위로/아래로** 버튼으로 목록을 구성한다.
- **방문자에게 공개**를 해제하면 관리자는 확인할 수 있고 방문자에게는 표시되지 않는다.
- **목록에 적용 → 전체 저장** 순서로 저장한다. 닫기를 누르면 편집창에서 적용하지 않은 변경이 취소된다.
- 모든 항목을 삭제하고 저장하면 방문자 화면의 FAQ 영역도 사라진다. 관리자에게는 목록 관리 버튼이 남는다.
- 질문과 답변은 한국어 원문으로 관리하며 기존 번역 기능을 따른다. 이전 직접 편집 기능으로 수정한 기본 질문·답변은 목록 관리로 전환할 때 유지한다.
