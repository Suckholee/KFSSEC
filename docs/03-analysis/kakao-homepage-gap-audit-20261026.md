## 10/29 이메일 로그인 및 통합 회원 연결

- 이메일 로그인은 Supabase Auth의 일회용 이메일 링크/코드 인증을 사용한다. 홈페이지에 비밀번호를 새로 저장하지 않는다. 연결된 인증 서비스에서 이메일 활성화 및 자동 인증 해제 상태를 확인했다.
- `내 정보 설정`에서 이메일 인증 또는 카카오 OAuth 인증을 추가한다. 로그인 상태를 암호화된 연결 요청에 바인딩하고 다른 계정으로 바뀌거나 요청이 만료되면 연결을 거절한다. 이름·연락처 이메일 일치만으로 합치지 않는다.
- 기존 카카오 회원 ID는 유지한다. 별도로 가입한 이메일 회원이 있는 경우 양쪽 인증 후 그 레코드가 현재 회원의 원본 ID를 참조하도록 연결한다. 과거 세션도 서버에서 같은 회원을 조회한다. 이메일·카카오 로그인 수단의 연결 인덱스는 비공개 암호화 저장소에 보관한다.
- 정회원 여부와 관리자 권한은 서버의 두 기존 레코드에서 보존한다. 브라우저에서 보낸 관리자·정회원 필드는 가입·내 정보 수정에 반영하지 않는다. 연결 후 권한 회수는 양쪽 로그인에 즉시 적용한다. 관리자 본인 권한 해제 제한은 연결 전 ID로도 우회할 수 없도록 원본 ID로 확인한다.
- 관리자 회원관리에서 실제 과정 선택·수강 상태를 저장할 수 있다. 회원은 내 정보에서 같은 수강내역을 확인한다. 기존 샘플 회원/수강관리 메뉴는 실제 회원관리로 연결했다. 수강 등록은 결제 기능이 아니며 과거 샘플 수강생을 실회원에 임의 배정하지 않는다.
- 기존 두 회원의 저장된 수강내역을 과정 ID로 병합한다. 같은 과정의 추가 기록은 linkedHistory와 원본 레코드에 보존한다. 기존 문의 신규 작성은 원본 회원 ID로 기록한다.
- 계정 연결은 원본 회원 순서대로 잠금을 획득하여 교차 연결 충돌을 거절한다. 대상 레코드를 먼저 준비하고 원본의 연결 포인터를 마지막에 기록한다. 서버 장애로 잔여 잠금이 남으면 운영자 점검 후 복구해야 하며, 불확실한 잠금을 자동으로 무시하지 않는다.
- 인증 코드 오류·이메일 불일치·연결 중 세션 교체 거절, 양방향 카카오/이메일 연결, 원본 ID·수강내역·권한 유지, 과거 세션의 원본 조회, 위조 세션 차단 등을 자동 검사했다. 이메일의 실제 수신 및 링크 복귀는 제공받은 테스트 주소로 배포 후 확인한다.
