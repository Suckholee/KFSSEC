# 단톡방 요청 / 운영 홈페이지 대조 및 반영

기준: 2026-10-26, https://www.kfssec.com. 대화 기준 8/12–10/25. 공개 운영 화면(컨설팅 교수 프로필, 파트너스), 공개 사이트 설정, 해당 배포 소스를 대조했다. 비공개 회원·문의 DB는 읽지 않았다.

## 우선 반영

| P2 | 첫 0~11초 실사 요청, 30초~1분 소개영상 | 첫 11.533초를 실제 전달 행사 사진·정장 이사장 사진·공식 로고로 교체. 31.734초, 기존 음성·후반부 재사용. 마지막 반복 연결은 기존 도형에서 실사로 전환되므로 연출 재검토 가능 |

명단 전환은 profileDirectoryVersion 1 기준으로 한 번 적용한다. 첫 전체 저장 이후 관리자가 삭제하거나 순서를 바꾸어도 기본 인물이 자동으로 복원되지 않는다. 기존 교육원 프로필과 관리자 입력 내용을 보존한다.

## 기존 반영 확인

- 사무국 김근혜 사무국장·조범진 사무주임과 조직도 편집은 직전 배포에 포함.
- 교수진 운영 데이터의 순서는 이상정 → 주정자 → 신충섭 → 진익준 → 조춘봉. 기존 실사 이미지 주소가 저장되어 있음.
- 파트너스 공개 화면에 협약 현장 15건, 파트너 로고·롤링 기능 존재.
- 공지 배너 및 공지 목록의 게시물 상세 연결 기능 존재.
- 진익준 사례 및 컨설팅 FAQ 3개, 홈페이지 FAQ 편집 기능 존재.
- 기존 소개영상 31.734초였으나 첫 11초에 도형 애니메이션이 남아 있었음.

## 남은 확인 / 자료 필요

1. 사용자 명시 승인 후 김근혜 계정을 단톡방에서 알려준 이메일과 대조해 관리자 지정 완료. 조범진 이름의 가입 완료 계정은 없어 미지정. 조범진 가입 후 김근혜 관리자가 회원관리에서 지정 가능. 과거 공개 기본 비밀번호 로그인은 차단했으며 운영자 접속에는 별도 안전한 인증 설정이 필요함.
2. 이득식·정보헌 고문의 고해상도 원본 사진과 확정 약력: 대화 첨부 속 자료의 원본 확보 필요. 현재 확인된 이름·직함만 등록.
3. 2022년 행사 사진은 단톡방에서 개인톡 압축파일로 전달했다고 언급. 현재 작업 폴더에서 확인된 행사 원본은 2024·2025년. 2022년과 10/19 행사 사진의 원본을 확보해야 새 갤러리를 완성할 수 있음.
4. 상도생활권추진위원회 협약서 및 2024 타이베이 감사장 원본 이미지: 텍스트 기록만 반영했으며 이미지 추가 필요.
5. MOU 문서 공개 범위: 사무국장의 제한 요청 뒤 이사장 허용 답변이 있으나 정확히 어느 이미지를 지칭했는지 미확정. 신규 문서 원문 전체를 임의 공개하지 않음.
6. HWP·DOC 참가신청서, 심사/면접요건 원본과 공식 행사 명칭은 원문 기준 재검토 필요. 기존 선정시상식 게시물 명칭을 일괄 변경하지 않음.
7. 카카오 실제 신규가입·알림톡 발송, 이사장 채널 연결, AI 블로그 자동 발행·캘린더는 외부 계정 설정과 실발송·실게시 검증 필요. 이번 배포에서 외부 메시지·블로그 게시를 실행하지 않음.

## 검증

- 관리자 지정 계정만 접근, 위조·만료 세션 차단, 일반 회원의 관리자 승격 차단, 권한 회수 즉시 반영, 외부 출처 로그인 요청 거절, 비회원 문의 거절.
- 기존 카카오 가입/회원 정보 수정 및 회원 구분 테스트 통과.
- 별도 명단·다중 개행 분리·한 번만 수행되는 고문 등록·명시적 빈 명단·사용자 순서 보존 검증.
- 기존 콘텐츠 직접 편집/목록/FAQ 자동 검증 포함 전체 18건.
- 로컬 브라우저: 운영자 로그인, 전문가 추가, 전체 저장, 새로고침 후 유지, 교육원 명단과 분리, 주정자 개행, 도움말 확인. 모바일 390px 폭에서 문서 가로 넘침 없음 확인.
- 영상: 전체 디코딩 오류 없음, 31.734초, 2초/9초 프레임 육안 확인 후 얼굴 잘림 수정. 음성 청취는 검증하지 않음. 기존 음성 복사, 신규 음성 합성 및 외부 생성 API 사용 0회.

## 운영 확인

2026-10-26 운영 도메인 배포 및 공개 화면에서 교수진 분리, 고문 추가, 주정자 약력, /help, 상도 협약·타이베이 감사장 확인. 비로그인 콘텐츠 수정·문의 등록은 HTTP 401, 새 실사 소개영상 HTTP 200 확인.

## 2026-10-26 추가 점검 및 정정

- 위 초기 점검의 사진 확보 필요 항목은 갱신한다. 이득식·정보헌·박상혜·정기엽의 카카오톡 원본 프로필 카드 4개를 확보하여 가로형 전체 이미지와 텍스트 약력으로 반영했다. 기존 관리자 사진·약력은 보존한다. profileDirectoryVersion 2를 저장한 뒤 삭제한 인물은 복원되지 않는다.
- 운영 /about/speech에서 이사장 실제 사진 로드와 인사말 본문 표시를 확인했다. 위 네 분의 자료는 /about/faculty 교수진 소개에 해당한다. 운영 화면에서 첫 두 명은 이름·직함만 있고 나머지 두 명은 빠져 있던 것을 확인하여 수정했다.
- 소개영상 첫 사진의 확대·이동 효과를 제거했다. 같은 사진의 1초/3초 영역 픽셀 차이 평균 23.44117 → 0.00386. 전체 디코딩 정상, 새 파일명으로 캐시 갱신.
- 10/19 사진은 카카오톡 첨부에 존재한다. 홈페이지 갤러리에 반영하는 작업이 남아 있다. 2022년 개인톡 압축파일은 미확보다.
- 컨설팅 사례 데이터는 브랜드·지역·역할 텍스트 목록이다. 사례별 원본 사진 반영이 남아 있다.
- AI 블로그 화면은 setTimeout 기반 템플릿 생성과 정적 일정 시안이다. 실제 AI 생성·자동 발행·스케줄러는 미구현이다. 단톡방의 다음 미팅 검토 항목으로 별도 구현이 필요하다.
- 알림톡 발송 서버 및 이사장 카카오 채널 직통 링크는 미구현이다. 단순 외부 설정이나 실발송 검증만 남았다는 기존 표현을 정정한다.
- 전체 홈페이지 재감사는 진행 중이며, 남은 자료·연동 요청까지 전부 완료한 상태로 간주하지 않는다.
