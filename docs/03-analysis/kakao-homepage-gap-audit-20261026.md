## 아직 확정 또는 자료·연동이 필요한 항목

- **직통 상담 채널**: 10/1 문구는 “컨설팅 상담 접수 시 이사장님 채널 직통 연결”. 이를 카카오톡 채널로 단정할 근거는 부족하다. 사용자에게 설명을 정정했으며 연결 방식 확정 전 임의 링크나 새 채널을 만들지 않았다. 기존 홈페이지 상담 접수는 유지한다.
- **2022 행사 원본**: 단톡방에서 개인톡 압축파일 전달로 언급됐지만 해당 파일 미확보. 기존 2024·2025 자료와 이번 2026 앨범을 다른 연도로 표시하지 않는다.
- **컨설팅 사례 사진 및 추가 행사 사진**: 확정된 사례별 원본, 앨범 분류가 필요하다. 이번 배포 사진은 2026 선정식 원본 2장이다.
- **상도 협약서·타이베이 감사장**: 공개할 정확한 원본 이미지와 범위 확인 필요. 일반 현장 사진과 협약서 원문을 혼동해 공개하지 않는다.
- **이사장 2002~2017 누락 약력, 공식 HWP·DOC 신청서·심사/면접 요건**: 원문과 현재 자료의 최종 대조 필요. 추정 내용이나 임의 서식을 공식 문서로 만들지 않는다.

- **카카오 알림톡**: 발송 서버·승인 템플릿·발송 서비스 미연동. 카카오 로그인과 별개이며 실제 발송을 완료한 상태가 아니다.
- **AI 블로그 자동 발행**: 기존 화면은 템플릿 생성·정적 일정 시안이다. 9월 대화의 다음 미팅 검토 대상으로 실제 AI 생성·블로그 자동 발행·스케줄러는 미구현이다.
- **베트남어**: 현재 ko/en/ja/zh만 활성화. 10/1 요청은 확장 구조 준비이며 베트남어 번역본·범위 확정이 필요하다. 영문을 베트남어 번역 완료로 표시하지 않는다.
