# 인라인 관리자 전면 보완 — 2026-10-20

## 운영자 사용법

1. 관리자 로그인 후 수정할 페이지와 탭을 연다.
2. ‘이 영역 관리’를 누르거나 왼쪽 ‘관리 범위 목차’에서 영역을 선택한다. 선택 범위는 테두리로 강조된다.
3. 안내 문구는 ‘제목·설명·이미지 수정’, 반복 자료는 이름이 표시된 ‘원본 목록 관리’, 강좌·명장 등은 전용 관리 도구를 연다.
4. 원본 목록에서 내용·사진·중첩 목록·추가·삭제·순서·공개를 설정한다. 많은 자료는 목록 검색을 사용한다.
5. ‘미리보기에 적용’ 후 상단 ‘방문자 시점’으로 확인하고 ‘전체 저장’한다. 창에서 적용하지 않고 닫으면 그 창의 변경만 취소된다.

문구·사진을 클릭하면 연결된 편집기가 열린다. 동작이 있는 버튼·링크는 기존 탐색을 유지하고 두 번 클릭으로 편집한다. 관리자 표시줄은 본문 위에 따로 배치해 제목과 겹치지 않게 했다. 원본 자료의 화면 복제 문구는 별도의 덮어쓰기로 편집하지 않는다.

FAQ: 교육·자격증 > 자격과정 안내의 FAQ 영역은 기존 질문·답변 전용 도구를 사용한다. 커뮤니티 > 주요문의(FAQ)는 해당 영역의 ‘커뮤니티 FAQ·분류 목록 관리’에서 질문·답변·분류·순서·공개를 관리한다.

## 데이터 보존

- 연혁·12대 방향의 최초 부분 수정 전에 원본 전체 목록을 복제한다. 이웃 항목과 중첩 자료를 보존한다.
- 저장된 빈 목록 []을 유효한 결과로 취급한다. 삭제한 갤러리 기본 자료를 자동으로 추가하거나 사진을 임의로 치환하지 않는다.
- 저장 요청과 부모 상태 반영을 분리해 동일한 내용을 두 번 저장하지 않는다. 저장 중 추가 편집을 막고 실패 시 초안을 유지한다.
- 원본 자료 관리 창은 독립 초안을 사용한다. 취소하면 저장 데이터나 페이지 초안이 바뀌지 않는다.
- 중첩 목록의 비공개 설정도 방문자 화면에서 반영한다. 공통 푸터는 global 설정을 사용한다.
- 기존 자격과정 이름·설명·포스터 수정값을 새 원본 목록으로 보존한다.
- 배포는 코드만 변경하며 운영 콘텐츠를 기본값으로 덮어쓰는 작업을 수행하지 않는다.
